# 📖 説明 (日本語)

`AI-translate-cmd` は、Rust ベースのコマンドラインツールで、AI モデル（Ollama など）を使用してテキストを繁体字中国語に自動翻訳します。

## ✨ 主な機能

- **効率的な処理**: 大容量ファイルのチャンク読み込みと翻訳をサポートし、メモリ使用量を抑えます。
- **スマートなセグメント分割**: 文末の句読点を自動的に検出し、文章の途中で翻訳が途切れないようにします。
- **進捗表示**: ターミナルにリアルタイムの翻訳進捗率を表示します。
- **多言語対応**: さまざまな入力言語（英語、日本語など）をサポートしています。

## 🚀 クイックスタート

### 1. 環境設定

ローカル設定ファイルを作成します：
```bash
cp config.example config.local
```

`config.local` を編集し、Ollama の URL とモデル名を記入してください。
**推奨モデル**: `translategemma:4b` (翻訳タスクに最適化)。

### 2. テストファイルの準備

英語または日本語のサンプルファイルを用意します：
```bash
# 英語サンプル
echo "Hello, how are you?" > sample-en.txt

# 日本語サンプル
echo "こんにちは、元気ですか？" > sample-ja.txt
```

### 3. 翻訳の実行

以下のコマンドを実行します：
```bash
# 英語サンプルの翻訳
cargo run -- en sample-en.txt

# 日本語サンプルの翻訳
cargo run -- ja sample-ja.txt
```

## 📂 出力について

結果は標準出力ではなく、ファイルに書き込まれます：
- デフォルト: `元のファイル名-out.txt` (例: `sample-en-out.txt`)。
- ファイルが既に存在する場合、番号が自動的に増えます: `元のファイル名-out-1.txt`, `元のファイル名-out-2.txt` ...
